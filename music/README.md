# Sonic Music — Version 40.0

An independent Android music companion with an Apple Music-inspired visual direction.

## Features
- Dark premium interface with Home, Search and Library sections.
- Search songs, artists, genres and playlists through the official YouTube app/site.
- Open local audio files through Android's document picker and play them in-app.
- Mini-player controls for locally selected audio.
- Long-press a discovery item to add or remove it from Favorites.
- Separate application ID and APK from the iOS Experience launcher.

## Important playback boundaries
YouTube discovery opens official YouTube search results. This app does not extract streams, bypass ads, simulate YouTube Premium, or promise background playback from YouTube. YouTube playback and account features are governed by YouTube's app, service and regional availability. Local audio playback is handled by Android MediaPlayer.

## Build
Run `gradle :music:assembleDebug`. The APK is generated at `music/build/outputs/apk/debug/music-debug.apk`.
